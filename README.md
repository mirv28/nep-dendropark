# nep-dendropark

Инструкция по запуску интерактивно-образовательной информационной системы "Непейцевский дендропарк"

dendropark

├───README.md # файл инструкции

├───back
│ └───app.py # Точка входа, маршруты навигации
│
└───front

├───history.html # верстка страницы истории

Шаг 1: Скачайте проект
1.1 Скачайте папку с проектом в удобное место на вашем компьтере.

Шаг 2: Установите Visual Studio Code
2.1 Скачайте Visual Studio Code с сайта: https://code.visualstudio.com/.
2.2 Установите Visual Studio Code, следуя инструкциям на сайте.

Шаг 3: Установите PostgreSQL
3.1 Скачайте и установите PostgreSQL с сайта: https://www.postgresql.org/.
3.2 Создайте новую базу данных и запомните параметры подключения
(имя базы данных, имя пользователя, пароль).
3.3 Импортируйте базу данных. ПКМ по созданной базе данных -> restore -> в filename выберите файл my_base.sql

Шаг 4: Настройте проект
4.1 Откройте Visual Studio Code и загрузите папку с проектом,
разархивированную на Шаге 1, установите с помощью pip библиотеки flask, flask_cors, psycopg2, json либо введите команду pip install -r requirements.txt
4.2 Откройте файл back/app.py, найдите 16 строку, измените параметры dbname и password (и другие опционально) на свои
4.3 В в этом же app.py измените логин (login) и пароль (password) от административной панели (рут @app.route("/login", methods=["POST"]), строка 451)
4.4 Откройте файл front/js/map.js и измените в переменной API_URL на свой ip (если не знаете, перейдите в шаг 5.1 и вернитесь)
данных.
4.5 Откройте файл front/js/admin.js аналогично измените API_URL как в 4.3
данных.

Шаг 5: Запустите систему
5.1 Введите команду для запуска сервера в терминале VS code:
cd back
python app.py
Вы увидите ip адрес вида http://168.192.0.1:5000
5.2 В другом терминале VS code введите команду для клиента:
cd front
python -m http.server 5500
5.2 Откройте браузер и перейдите по адресу: `http://ххх.ххх.ххх.ххх:5500` (ваш адрес, но порт 5500)

Шаг 6: Настройте запуск для работы геолокации (опционально)
6.1 Совершите шаг 5.1
6.2 Откройте другой терминал и введите команду для туннеля сервера:
lt --port 5000
6.3 Совершите шаг 4.4, но вводите адрес из предыдущего шага
6.4 Совершите шаг 5.2
6.5 Откройте другой терминал и введите команду для туннеля клиента:
lt --port 5500
6.6 Откройте браузер и перейдите по адресу из предыдущего шага
